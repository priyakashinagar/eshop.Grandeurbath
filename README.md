# Grandeur Bath website (frontend)

React + Vite + Tailwind + Ant Design storefront for Grandeur Bath. The backend API is a separate project:
**eshop.Grandeurbath_backend** (local folder `../grandeurbath-backend`).

## Run locally

```bash
npm install
npm run dev          # http://localhost:5173
```

Start the backend first (`npm run dev` in the backend folder, port 5000). Vite forwards `/api` and `/uploads`
to it. To use another backend: `API_PROXY=http://localhost:5100 npm run dev`.
Without a backend the site still opens with sample products, but login, orders and payments do not work.

## Build and deploy (Vercel)

```bash
npm run build        # vite build + pre-rendered policy pages
```

- Set `VITE_API_URL` in Vercel (Project > Settings > Environment Variables) to the deployed backend address,
  then redeploy. Add the website address to the backend's `CORS_ORIGINS`.
- `vercel.json` sends every route to the app and serves the pre-rendered policy pages at clean URLs.

## Policy pages for Razorpay

These pages contain real HTML (readable without JavaScript), generated by `scripts/prerender-policies.mjs`:

| Page | URL |
|---|---|
| Privacy Policy | `/privacy-policy` |
| Terms and Conditions | `/terms-and-conditions` |
| Cancellations and Refunds | `/cancellation-and-refund` |
| Shipping Policy | `/shipping-policy` |
| Contact Us | `/contact-us` |

Their text comes from `scripts/policy-content.json`. Inside the app, the same pages use the content the admin
edits through the backend (`/api/storefront`).

## Structure

- `src/pages`: store pages (home, listing, product, cart, checkout, orders, account, policies...)
- `src/components`: header, footer, product card and shop components
- `src/api/index.js`: every backend call
- `src/data`: built-in fallback content, replaced at start-up by the backend's content
- `src/store`: cart, wishlist, login and orders state
